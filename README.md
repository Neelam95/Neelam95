## 📌 Featured Project

### 🚨 StreamSentinel
> Agentic AI pipeline intelligence for real-time financial data streams

| Feature | Details |
|---------|---------|
| 🔍 Detection | Real-time anomaly detection on live Kafka streams |
| 🧠 Diagnosis | LLM explains root cause in plain English |
| ⚖️ Blast Radius | Deterministic impact scoring — LOW / MEDIUM / HIGH |
| 🔧 Remediation | Auto-fixes LOW/MEDIUM, escalates HIGH to human |
| 📰 Narration | Auto-generates plain-English incident post-mortem |
